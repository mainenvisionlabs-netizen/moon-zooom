# MOON ZOOOM

Static site for Moon Zooom, the vintage shop at 813 Pacific Avenue in Santa Cruz.

## Local preview

```bash
python3 -m http.server 4173
```

Open http://localhost:4173

## Layout

- `index.html` — the shop page
- `css/styles.css` — styles
- `fonts/` — self-hosted Caveat, Shrikhand, and Special Elite
- `404.html` — missing-page page

Hours, phone, email, and Instagram are the public listings for the store. Hours can change; the page says so.
